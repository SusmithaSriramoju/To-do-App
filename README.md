# To-Do App

A simple To-Do application built using HTML, CSS, and JavaScript.

## Features
- Add tasks
- Delete tasks
- Mark tasks as completed
- Data persistence using Local Storage
- Clean and responsive UI

## Technologies Used
- HTML
- CSS
- JavaScript

## Future Improvements
✏️ Edit tasks
🔍 Filter tasks (All / Completed / Pending)
📅 Add due dates
🌙 Dark mode
